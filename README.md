
# Lane Miles Data Preparation

R-based workflows for preparing datasets used in
statistical estimation of roadway lane miles.

## Project Status

This repository is being reorganized to improve
reproducibility, documentation, and maintainability.

## Repository Structure

- `archive/` - Legacy R scripts and R Markdown notebooks.
- `R/` - Data preparation and processing scripts (planned).
- `config/` - Input/output paths and parameters (planned).
- `docs/` - Data sources and methodology (planned).

## Getting Started

Setup instructions will be added as the existing
scripts are migrated into the new workflow.

## Maintenance

New development should take place outside `archive/`.
Changes should be reviewed through GitHub pull requests.
